Lighthouse Notes

A small demo app that doesn't handle its own logins. Instead, it trusts Aegis ID — a separate Identity Provider — to authenticate you, and only ever receives a signed statement of who you are.

Continue with Aegis ID

This mirrors exactly what happens when an app offers "Sign in with Okta," "Sign in with Google," or similar: the app you're using never sees your password, and never needs to.

What you're about to see

Clicking through will redirect you to Aegis ID to log in, then back here. Along the way, a live trace panel will narrate each step — including exactly which cryptographic operation is happening and why it matters. Nothing here is production software; see the repository's README for what's simplified and why.
